**Program Mencari Nama Siswa di dalam Daftar Absensi**

## Deskripsi Singkat ##

Program ini digunakan untuk mencari nama siswa dalam daftar absensi dengan menggunakan sequential search, program ini menggunakan perulangan untuk menelusuri seluruh data sehingga dapat mengetahui apakah nama ditemukan dan berapa kali nama tersebut muncul dalam daftar absensi. Program bekerja dengan memeriksa setiap elemen dalam daftar satu per satu untuk mencocokkan nama yang dicari oleh pengguna. Program ini memiliki fungsi untuk melakukan proses pencarian, menghitung jumlah kemunculan nama dalam data absensi, menampilkan daftar siswa, dan menampilkan hasil pencarian. Program juga menggunakan perulangan untuk menelusuri seluruh data sehingga dapat mengetahui apakah nama ditemukan dan berapa kali nama tersebut muncul dalam daftar absensi.
