**Program Mengurutkan Harga Barang Menggunakan Bubble Sort**

**Deskripsi Singkat**

Program ini merupakan program yang digunakan untuk mengurutkan harga barang dari yang termurah ke termahal dengan menggunakan algoritma bubble sort untuk membandingkan dan menukar posisi elemen agar tersusun secara berurutan. Program ini memiliki fungsi untuk menukar posisi dua elemen, fungsi pengurutan data, dan fungsi untuk mengelola input dari pengguna. Program ini juga menggunakan perulangan agar pengguna dapat memasukkan beberapa data harga barang sesuai jumlah yang ditentukan, setelah itu program akan menampilkan data sebelum dan sesudah diurutkan secara rapi.
